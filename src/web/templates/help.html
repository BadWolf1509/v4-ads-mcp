O que é o V4 Ads MCP

Servidor MCP (Model Context Protocol) interno V4 que conecta as contas Google Ads que você gerencia ao Claude, Codex e Cursor. Você pede em linguagem natural — "performance da conta X últimos 30 dias", "pause keywords sem conversão" — e o assistente executa via ferramentas auditadas + governança (dry-run + apply para mutações).

Como configurar — passo a passo

  1. Login no painel — acesse /login com sua conta @v4company.com.
  2. Espere o admin liberar contas — em /accounts você verá as contas que pode gerenciar.
  3. Crie uma sessão MCP em /sessions — copie o Bearer token (aparece UMA vez).
  4. Configure seu cliente com os snippets abaixo.

Claude Desktop

FAQ

"Tool not found" no Claude

Reinicie o Claude Desktop completamente (sair pelo system tray). Verifique que o Bearer token está exatamente como copiado, sem espaços extras.

Perdi o token, e agora?

Tokens só aparecem uma vez. Crie uma nova sessão em /sessions e descarte a anterior em Revogar.

Não vejo as contas que deveria gerenciar

Peça pro admin V4 da sua unidade liberar via /admin/access.

"acesso negado" depois de logar com Google

Seu email não está na allowlist. Peça pro admin te adicionar em /admin/invites.
