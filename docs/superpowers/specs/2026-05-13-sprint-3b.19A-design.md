# Sprint 3b.19A — `create_conversion_action` design

**Status:** Draft → user review pending
**Owner:** Wellington (`wellinton.ribeiro@v4company.com`)
**Date:** 2026-05-13
**Predecessor sprints:** 3b.14 (`create_ad_group`), 3b.16 (`create_rsa`), 3b.18 (`update_rsa`)

## Goal

Adicionar MCP tool `create_conversion_action` para que gestor V4 configure conversion tracking via natural-language no Claude Code em vez de Google Ads UI. Começa a fechar o gap UX-1 (Sprint 3b.7) — 22 de 23 contas V4 usam placeholder tracking (1:1 default), o que torna ROAS misleading e impede análise de performance.

Esta sprint cria o **primeiro passo** do setup de tracking (criar a ConversionAction). Os passos seguintes (instalar tag para WEBPAGE, importar offline conversions para UPLOAD_*) ficam fora de escopo v0 — tag install é manual via Google Ads UI; offline import depende do Standard Access verdict ainda pendente (case `26521440673`).

## Context / why now

- **Sinal de produto:** dogfood expansion em 3 contas (3b.7 sign-off) confirmou que placeholder tracking é endêmico em V4. ML Antiguidades é a exceção (PURCHASE WEBPAGE real, AOV R$ 515, ROAS 100.79); Mestre da Obra + Expresso Turismo + a maioria das contas V4 ainda dependem de placeholder.
- **Low quota:** ~1 mutation por setup de tracking. Não bloqueado por Standard Access verdict.
- **Padrão consolidado:** 18 sprints de create/update/remove patterns — esse é o **terceiro create-pattern** (após `create_ad_group`/3b.14 + `create_rsa`/3b.16). Risco baixo.
- **Cross-cutting features herdadas:** F13 (resource_names auto-returned via run_mutation, Sprint 3b.15) — zero code novo necessário aqui, gestor já vê o ID do ConversionAction criado.

## Non-goals (v0)

- **Tag generation/installation** (WEBPAGE) — gestor instala gtag/GA4 tag manualmente via Google Ads UI > Tools > Conversions, ou usa `get_conversion_actions` pra ler `tag_snippets` server-generated.
- **Offline conversion import** — separate tool `import_offline_conversions` em sprint futura, Standard Access blocked.
- **Attribution model override** — Google usa default; gestor edita via UI se precisar.
- **Lookback windows** (click_through / view_through) — Google default 30/1 days; gestor edita via UI.
- **Status PAUSED on create** — sempre `ENABLED` (use case driver: gestor quer ativação imediata).
- **Remove/update ConversionAction** — sprints futuras se demanda surgir.
- **`OUTBOUND_CLICK`, `GET_DIRECTIONS`, `STORE_*` categories** — niche, excluídas do whitelist v0.
- **`CLICK_TO_CALL` + `WEBSITE_CALL` types** — niche em V4; UPLOAD_CALLS cobre offline call import workflow.

## Tool surface

### Name
`create_conversion_action`

### Description (PT-BR, dispatch hint to LLM)
```
Cria 1-5 ConversionActions no nivel customer. Cada action: name (1-100 chars) + category
+ type. Always-CONFIRM. Categorias supportadas (~18 values V4-focused): LEAD, PURCHASE,
SIGNUP, DEFAULT, SUBMIT_LEAD_FORM, BOOK_APPOINTMENT, REQUEST_QUOTE, PHONE_CALL_LEAD,
IMPORTED_LEAD, QUALIFIED_LEAD, CONVERTED_LEAD, ADD_TO_CART, BEGIN_CHECKOUT, SUBSCRIBE_PAID,
DOWNLOAD, CONTACT, ENGAGEMENT, PAGE_VIEW. Tipos: WEBPAGE (tag manual install), UPLOAD_CLICKS
(offline import via CRM), UPLOAD_CALLS (offline call import). Defaults: status=ENABLED,
currency=BRL, counting_type=ONE_PER_CLICK. Pre-flight rejeita nome duplicado.
Para tag/import setup, use Google Ads UI ou tools especificas (futuras sprints).
```

### Pre-flight helper

```python
# src/google_ads/queries/_common.py

async def validate_conversion_action_create(
    customer_id: str, actions: list[dict[str, Any]]
) -> str | None:
    """Pre-flight: rejeita nomes que ja existem na conta.
    
    Single GAQL batch query — retorna first-offender PT-BR error.
    Padrao Sprint 3b.5+ (validate_existing_*).
    
    Returns:
        None se OK, string com erro PT-BR se primeiro nome duplicado encontrado.
    """
    if not actions:
        return None
    names = [a["name"] for a in actions]
    quoted = ", ".join(f"'{_escape_gaql_string(n)}'" for n in names)
    query = (
        "SELECT conversion_action.name FROM conversion_action "
        f"WHERE conversion_action.name IN ({quoted})"
    )
    rows = await run_report(customer_id, query)
    existing = {r["conversion_action"]["name"] for r in rows}
    for a in actions:
        if a["name"] in existing:
            return (
                f"ConversionAction '{a['name']}' ja existe na conta. "
                "Use outro nome (nomes sao unicos por customer)."
            )
    return None
```

Reusa `_escape_gaql_string` helper (precedent: `validate_existing_rsas_for_update`).

### Builder

```python
# src/google_ads/mutates/conversion_actions.py (NEW FILE)

"""Mutate builders for conversion_action operations."""

from typing import Any

from src.google_ads.mutates._common import register_builder


@register_builder("create_conversion_action")
def build_create_conversion_action(
    client: Any, customer_id: str, payload: dict[str, Any]
) -> list[Any]:
    """payload: {conversion_actions: [{name, category, type, counting_type?, value_settings?}]}
    
    Defaults: status=ENABLED, currency=BRL (V4 invariant),
    counting_type=ONE_PER_CLICK if omitted.
    
    Note: ConversionAction proto uses `type_` (underscore suffix)
    because `type` is a Python reserved word — google-ads SDK convention.
    """
    operations: list[Any] = []
    cat_enum = client.enums.ConversionActionCategoryEnum
    type_enum = client.enums.ConversionActionTypeEnum
    status_enum = client.enums.ConversionActionStatusEnum
    counting_enum = client.enums.ConversionActionCountingTypeEnum
    for spec in payload["conversion_actions"]:
        op = client.get_type("MutateOperation")
        ca_op = op.conversion_action_operation
        ca = ca_op.create
        ca.name = spec["name"]
        ca.category = cat_enum[spec["category"]]
        ca.type_ = type_enum[spec["type"]]
        ca.status = status_enum.ENABLED
        ca.counting_type = counting_enum[
            spec.get("counting_type", "ONE_PER_CLICK")
        ]
        if "value_settings" in spec:
            vs = spec["value_settings"]
            ca.value_settings.default_currency_code = "BRL"
            if "default_value_brl" in vs:
                ca.value_settings.default_value = vs["default_value_brl"]
            if "always_use_default_value" in vs:
                ca.value_settings.always_use_default_value = vs["always_use_default_value"]
        operations.append(op)
    return operations
```

**Validation note:** confirmar via context7 `google-ads-python` docs durante implementation que (a) atributo é `ca.type_` (not `ca.type`), (b) `value_settings.default_value` aceita float diretamente (não precisa de micros conversion como em CPC bids), (c) `default_currency_code` é string field não enum.

### Audit summary

```python
# src/mcp/tools/create_conversion_action.py

def _build_params_summary(actions: list[dict[str, Any]]) -> dict[str, Any]:
    """Audit summary — NO copy text (per spec §3.6).
    
    Captures shape distribution sem expor nomes (gestor pode re-read via
    get_conversion_actions se precisar detail).
    """
    return {
        "count": len(actions),
        "categories": dict(Counter(a["category"] for a in actions)),
        "types": dict(Counter(a["type"] for a in actions)),
        "with_default_value": sum(
            1 for a in actions
            if "value_settings" in a and "default_value_brl" in a["value_settings"]
        ),
        "with_always_use_default": sum(
            1 for a in actions
            if "value_settings" in a and a["value_settings"].get("always_use_default_value")
        ),
    }
```
