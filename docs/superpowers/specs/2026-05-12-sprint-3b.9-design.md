## 1. Goal

Fix P3 dogfood F7: `get_recommendations` retorna `{type: "FORECASTING_SET_TARGET_CPA", type_pt: "FORECASTING_SET_TARGET_CPA"}` — `type_pt` field duplica `type` quando não há tradução PT-BR, confundindo gestor que pensa que a tradução funcionou.

Single-file edit em `src/mcp/tools/get_recommendations.py`:
1. Adicionar 5 entries no `_TYPE_PT` mapping (forecasting + Performance Max variants comumente emitted)
2. Mudar fallback de `_TYPE_PT.get(type_str, type_str)` para `_TYPE_PT.get(type_str)` (default `None`)
3. Atualizar tool description pra explicitar contract (`null` quando não reconhecido)
4. 3 unit tests

Net delta: ~5 LOC source + ~30 LOC tests. Zero novos MCP tools (count stays 39).

## 2. Scope decisions

| # | Decisão | Resolução | Justificativa |
|---|---|---|---|
| 1 | Abordagem | **Hybrid (C)** — curated mapping additions + null fallback | Cobre o caso real do P3 dogfood (`FORECASTING_SET_TARGET_CPA`) E sinaliza claramente quando não há tradução. Best of both. |
| 2 | Quantas entries adicionar? | **5** | Cobertura proativa: forecasting + Performance Max variants são as categorias mais comuns que Google Ads emite atualmente. YAGNI para os outros ~50 types raros. |
| 3 | Backward compat | **Quebrar contrato `type_pt == type`** | Evidence empírica (P3 dogfood) sugere gestores não dependem da duplicação — apenas confunde. Solo dogfood + zero outros consumers externos. |
| 4 | Atualizar tool description? | **Sim** | Mínima mudança (5 palavras) explicita contract (`null` caso não reconhecido). |
| 5 | Test scope | **3 tests** (null fallback + existing entry + new dogfood entry) | YAGNI testar todos 5 novos individuamente — test 3 prova o pattern. |

### 3.2 Fallback change

```python
# BEFORE (line 62):
"type_pt": _TYPE_PT.get(type_str, type_str),

# AFTER:
"type_pt": _TYPE_PT.get(type_str),  # None when no PT-BR mapping exists
```

### 3.3 Type hint impact

Return type da dict passa a ser `dict[str, str | None]` na key `type_pt`. mypy strict deve aceitar — dict[str, Any] já é o tipo declarado em `_row_formatter` return. Sem mudança necessária no signature.

## 5. Risks & mitigations

| Risk | Likelihood | Mitigation |
|---|---|---|
| Breaking change pra gestor que dependa de `type_pt == type` redundancy | Very Low | P3 dogfood evidence: gestores não dependem disso (apenas confunde). Zero external consumers (solo dogfood). |
| Novos 5 entries têm tradução PT-BR ruim | Low | Single review during implementation. Mudança fácil de iterar via 1-line edit. |
| mypy reclama sobre `dict[str, str | None]` | Low | Existing `_row_formatter` return type é `dict[str, Any]` — Any aceita None. Verify ao rodar gate. |
| Outras chamadas dependem do redundancy | Very Low | grep verificou: zero outros call sites do `get_recommendations` formatted output em outras tools. |

## 6. Out of scope (explicit)

- **Comprehensive Google Ads type mapping** (50+ types) — YAGNI. Adicionar reativo conforme dogfood expansion revela novos missing types.
- **i18n framework / per-locale translations** — PT-BR é o único locale (V4 BR-only).
- **Apply/dismiss tools change** — `apply_recommendation` + `dismiss_recommendation` não tocam `type_pt`. Não afetados.
- **Translation quality review** — single iteration, no expert review needed (Wellington é speaker nativo + gestor real).
