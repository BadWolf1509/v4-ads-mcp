## 1. Goal

Closes silent-acceptance bug family **6ª variante (F12)**: `update_keyword_bid` e `update_ad_group_bid` aceitam payloads em campaigns que usam auto-bidding strategies (MAXIMIZE_CONVERSIONS, TARGET_CPA, MAXIMIZE_CONVERSION_VALUE, etc) e produzem dry-run aparentemente bem-sucedido, mas Google **silenciosamente ignora** `cpc_bid_micros` updates nessas strategies (documentado oficialmente).

Ship pre-flight GAQL batch validation que rejeita hard se qualquer campaign no batch não estiver em strategy que honra `cpc_bid_micros` ({MANUAL_CPC, ENHANCED_CPC}). Match exato do pattern Sprint 3b.5 A3 (taxonomy validation em `apply_audience`).

## 2. Scope decisions

| # | Decisão | Resolução | Justificativa |
|---|---|---|---|
| 1 | Quais tools? | **Ambos: `update_keyword_bid` + `update_ad_group_bid`** | Mesma F12 bug class — Google ignora `cpc_bid_micros` em auto-bidding em ambos níveis. YAGNI não se aplica a bugs conhecidos. |
| 2 | Whitelist scope | **MANUAL_CPC + ENHANCED_CPC** (option B) | Tecnicamente correto: estas são as únicas strategies que honram `cpc_bid_micros` (Google Ads API v23 docs). MANUAL_CPM/CPV usam `cpm_bid_micros`/`cpv_bid_micros` — incluí-los re-introduziria F12 em outro field. ENHANCED_CPC é legacy mas ainda usa `cpc_bid_micros`. Empirical V4 distribution (7 accounts, 9 campaigns): MANUAL_CPC em SHOPPING confirmed; ENHANCED_CPC 0; auto-bidding domina SEARCH. |
| 3 | Hard reject vs warn | **Hard reject** | Match Sprint 3b.5 A3 + A4 pattern. Auto-bidding silent ignore é no-op real — warning + proceed deixaria gestor confuso. |
| 4 | Helper location | **`src/google_ads/queries/_common.py`** (shared) | DRY entre 2 tools. Same module que `value_proxy_warning`, `parse_date_range`, etc. |
| 5 | Test coverage | Unit (5 helper + 4 tools = 9 tests). Sem integration. | Sprint 3b.5 A3 pattern — mock `run_report` no helper test. Integration redundante. |
| 6 | Mixed-batch behavior | Return **first** offending campaign | YAGNI vs listing todos. Gestor fixa, re-roda, vê próximo se houver. |

## 3. Component specs

### 3.1 Helper compartilhado em `src/google_ads/queries/_common.py`

```python
async def validate_manual_cpc_strategy(
    manager_id: UUID,
    session_id: UUID,
    customer_id: str,
    ad_group_ids: list[str],
) -> str | None:
    """Returns PT-BR error string if any ad_group is in non-MANUAL_CPC/ENHANCED_CPC
    campaign; else None.

    Performs 1 GAQL batch lookup. Whitelist {MANUAL_CPC, ENHANCED_CPC} matches
    strategies que honram cpc_bid_micros field (Google Ads API v23 docs:
    https://developers.google.com/google-ads/api/docs/campaigns/bidding/override-strategies).

    Sprint 3b.8 (P3 dogfood F12 finding — silent-acceptance bug family 6th variant).
    """
    if not ad_group_ids:
        return None

    ids_clause = ", ".join(ad_group_ids)
    query = (
        f"SELECT ad_group.id, campaign.id, campaign.name, "
        f"campaign.bidding_strategy_type "
        f"FROM ad_group WHERE ad_group.id IN ({ids_clause})"
    )

    def _format(row: Any) -> dict[str, str]:
        return {
            "ad_group_id": str(row.ad_group.id),
            "campaign_id": str(row.campaign.id),
            "campaign_name": row.campaign.name,
            "strategy": row.campaign.bidding_strategy_type.name,
        }

    rows = await run_report(
        manager_id=manager_id,
        session_id=session_id,
        customer_id=customer_id,
        query=query,
        row_formatter=_format,
        operation_name="validate_manual_cpc_strategy",
    )

    WHITELIST = {"MANUAL_CPC", "ENHANCED_CPC"}
    for r in rows:
        if r["strategy"] not in WHITELIST:
            return (
                f"Campaign '{r['campaign_name']}' (id {r['campaign_id']}) usa "
                f"bidding_strategy_type '{r['strategy']}'. Manual CPC bids sao "
                f"ignorados nesta estrategia (Google API silent-failure). Mude "
                f"para MANUAL_CPC via update_campaign_bidding, ou ajuste budget/"
                f"targeting via outras tools."
            )
    return None
```

**Imports adicionados em `_common.py`:**
- `from uuid import UUID`
- `from typing import Any`
- `from src.google_ads.reports import run_report`

**Circular import check:** `reports.py` não importa de `queries/_common.py`. Adicionar import é seguro.

### 3.2 `update_keyword_bid.py` integration

Inserir após `target_count = len(bids_input)` (linha ~62):

```python
from src.google_ads.queries._common import validate_manual_cpc_strategy

# F12 pre-flight (Sprint 3b.8): reject if any campaign uses auto-bidding strategy.
# Google ignora cpc_bid_micros updates silenciosamente em non-MANUAL_CPC strategies.
ad_group_ids = list({b["ad_group_id"] for b in bids_input})
error = await validate_manual_cpc_strategy(
    manager_id=ctx.manager_id,
    session_id=ctx.session_id,
    customer_id=customer_id,
    ad_group_ids=ad_group_ids,
)
if error:
    return {"status": "error", "error": error, "operation": "update_keyword_bid"}
```

`ad_group_ids` deduplicado via set comprehension — payload pode ter múltiplas keywords no mesmo ad_group, GAQL não precisa duplicar.

## 5. Risks & mitigations

| Risk | Likelihood | Mitigation |
|---|---|---|
| ENHANCED_CPC missing from V4 survey → whitelist quebra account legacy | Low | Survey só viu 5 accounts; outras 18 podem ter ENHANCED_CPC. Whitelist inclui ele preventivamente. Se aparecer, gestor reporta. |
| Race condition: gestor muda strategy entre pre-flight e apply_change | Very Low | 10-min token TTL. Se acontecer, apply_change roda mas Google ignora silent (status quo). |
| GAQL batch latency adiciona ~200-400ms | Low | Mutate operations não são latency-critical. Trade-off acceptable. |
| Helper import circular | Very Low | Verified: `reports.py` não importa de `queries/_common.py`. |
| Tests usando MagicMock-everywhere (Sprint 3b.4 A4 lesson) | Low | Helper tests usam `monkeypatch.setattr("...run_report", ...)` com return value real. Match Sprint 3b.5 A3 test pattern. |
| Whitelist atualização futura (TARGET_CPC?) | Low | Set literal hardcoded — fácil de adicionar via 1-line PR se Google adicionar nova manual-bid strategy. |

## 6. Out of scope (explicit)

- **`update_campaign_bidding` strategy switcher** — gestor pode mudar strategy via this existing tool. Não vamos automatizar "rejeita → muda → aplica" sequence (gestor decision).
- **Whitelist por bid field** (MANUAL_CPM/CPV em outros tools) — out of scope: nossos tools só setam `cpc_bid_micros`. Se eventually shippar `update_keyword_cpm_bid`, ele terá seu próprio pre-flight com whitelist diferente.
- **Per-strategy error message customization** — single template PT-BR, mention strategy name. YAGNI.
- **Listing ALL offending campaigns em mixed batch** — return first only. Mantém erro conciso.
- **Integration tests** — Sprint 3b.5 A3 pattern provou que unit + mocked `run_report` é suficiente. Integration redundante.
