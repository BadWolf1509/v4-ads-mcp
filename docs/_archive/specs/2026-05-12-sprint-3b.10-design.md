## 1. Goal

Relocate `tests/unit/test_rate_limit.py` → `tests/integration/test_rate_limit.py` (single file move). File uses `testcontainers.PostgresContainer` (Docker required) + has `@pytest.mark.integration` markers per-test → pertence em `tests/integration/`, não `tests/unit/`.

**Coverage finding (descoberto durante design):** os 6 testes do file estão **dead em CI** hoje:
- CI step 1 (`pytest tests/unit tests/integration -m "not integration"`) → marker exclui
- CI step 2 (`pytest tests/integration -m integration`) → file não está em `tests/integration/`, não picked up

Move resolve esse gap — tests passam a rodar em CI step 2 (Docker integration).

Zero source code change. Zero novos MCP tools (count stays 39).
